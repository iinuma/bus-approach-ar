# リリースノート

Even Hub の審査では `supported_languages` ごとに必要。1〜3 行、コードの変更ではなく
利用者にとって何が変わったかを書く。初版はアプリの説明にする。
Add build の瞬間に確定し、あとから直せない（Tokyojihatsu の docs/release-notes.md）。

版は「アップロードの単位」。検証用の `.ehpk` は `npm run app:pack` で版を上げずに何度でも焼く。

## tagline（ポータルのプロジェクト設定・50 文字以内）

```
バス停で右を向けば、近づくバスと発車まであと何分か
```

## 0.2.0

### ja

```
川崎市バスと臨港バスの全停留所に対応しました。川崎駅など両社が止まるバス停では、両社の便をまとめて表示します。
```

## 0.1.0

### ja

```
大師橋駅前（臨港バス）の次の便の系統・行先・発車までの残り時間を表示します。
接近するバスを、右を向いた先の道路の上に表示します。スワイプで向きを合わせられます。
```
