# バス接近AR プライバシーポリシー

最終更新日: 2026-10-03

バス接近AR（以下「本アプリ」）は、Even Realities G2 向けに、バス停の次の便の系統・行先・
発車までの残り時間と、接近してくるバスの位置を表示するアプリです。本ポリシーは、本アプリが
扱う情報とその取り扱いについて説明します。

## 本アプリが利用する権限

### 位置情報（location）

**用途**: 現在地の近くにあるバス停を候補として表示するためにのみ使用します。

**取り扱い**: 取得した位置情報は**お使いのスマートフォンの中だけで処理され、外部に送信される
ことはありません**。近くのバス停の判定は、アプリに同梱されたバス停の座標と端末内で照合して
行います。開発者を含む誰も、あなたの位置情報を受け取りません。

位置情報の利用を許可しない場合でも、バス停を一覧から選べば他の機能は動作します。

### ネットワーク（network）

**用途**: 選んだバス停の時刻表と、バスの現在位置・運行情報を取得するためにのみ使用します。

**接続先**: 開発者が運営する中継サーバー
`https://ibvjlpkr6o3wkodz7izo6ctdhe0yajkz.lambda-url.ap-northeast-1.on.aws`
（Amazon Web Services、東京リージョン）にのみ接続します。中継サーバーは公共交通オープン
データセンター（ODPT）のデータから作った時刻表と、ODPT から取得したバスの運行情報を返します。

**送信される内容**: 選んだバス停を示す識別子（停留所の番号）だけです。中継サーバーはそのバス停の
時刻表と、そのバス停に関係するバスの運行情報を返します。
**位置情報や、あなたを特定できる情報は送信されません。**

## 端末内に保存される情報

次の情報を端末内に保存します。**端末の外に出ることはありません。**
本アプリをアンインストールすると削除されます。

- 最後に選んだバス停と乗り場（次回起動時にすぐ表示するため）
- 表示の向きの設定（右へ何度向いているか）

## 中継サーバーのログ

中継サーバーは、障害の調査のために動作ログ（処理日時、エラーの内容）を最大 7 日間保持し、
その後自動的に削除します。ログに位置情報は含まれません。

## 第三者への提供

本アプリが取得した情報を第三者に販売・提供することはありません。広告は表示せず、
アクセス解析ツールも使用していません。

## 運行データについて

本アプリが表示する時刻表・バスの位置・運行情報は、公共交通オープンデータセンターの提供データ
です。データの正確性・完全性は保証されたものではありません。発車までの残り時間には、到着する
バスがそのまま折り返すと仮定した推定を含みます。画面上部の道路は、バス停で右へ 60° 向いた
状態を想定した模式図で、実際の方位を示すものではありません。
