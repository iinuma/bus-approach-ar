# バス接近AR

Even Realities G2 向けの、バス接近表示アプリです。バス停と乗り場を選ぶと、次の便の系統・行先・
発車までの残り時間と、接近してくるバスの位置を G2 に表示します。
公共交通オープンデータチャレンジ2026 への応募作品として開発しています。

- [プライバシーポリシー](privacy-policy.md)

## 対応範囲

川崎市バス・川崎鶴見臨港バスの全停留所。両社が止まるバス停（川崎駅など）は、両社の便をまとめて表示します。
